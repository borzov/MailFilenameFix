# Mail Filename Fix

Расширение для Почты (Mail.app) на macOS, которое чинит искажённые имена
вложений:

```
utf-8''%D0%93%D1%80%D0%B0%D1%84%D0%B8%D0%BA%D0%B0-2.png   →   Графика-2.png
Ð¸Ð·Ð¾Ð±ÑÐ°Ð¶ÐµÐ½Ð¸Ðµ.png                                 →   изображение.png
```

## В чём проблема

Если файл в письме называется по-русски (или на любом другом языке, кроме
английского), Почта на Mac часто показывает вместо имени бессмыслицу. Такие
файлы неудобно искать, а с очень длинными именами — даже не получается
сохранить на диск.

Причин три, и выглядят они по-разному.

**`utf-8''%D0%93...` — ошибка самой Почты.** Отправитель кодирует имя файла
по стандарту (RFC 2231), а Почта на macOS — единственная из всех почтовых
программ — не умеет его раскодировать. На iPhone и в веб-почте те же письма
выглядят нормально. Ошибка живёт со времён macOS 11 и не исправлена до сих
пор (включая macOS 26).

**`Ð¸Ð·Ð¾Ð±ÑÐ°Ð¶ÐµÐ½Ð¸Ðµ.png` — «кракозябры», ошибка на стороне
отправителя.** Русское имя один раз прочитали не в той кодировке, и в письмо
уехал уже испорченный текст. Чаще всего так делают старые корпоративные
серверы и самописные рассылки. Расширение распознаёт такую порчу и
разворачивает её обратно.

**`Рекомендации_д_��-�,4-?�?�` — имя оборвано, дальше мусор.** Длинное имя
отправитель разбил на несколько закодированных кусков (так делает, например,
веб-почта Яндекса). Каждый кусок сам по себе правильный, но Почта не умеет
их склеивать: первый показывает, остальные превращает в мусор. Расширение
собирает куски в одно имя.

## Как это работает

Расширение встраивается в Почту штатным способом (через MailKit) и на лету
переписывает «непонятную» для Почты кодировку имени в ту, которую она
понимает (так кодируют Gmail и Outlook). После этого имя отображается
правильно везде: в списке вложений, при быстром просмотре и при сохранении.

При этом:

- письма на сервере не изменяются — исправление происходит только при
  отображении, на вашем Mac;
- в письме меняются только строки с именем файла, всё остальное остаётся
  байт в байт как было;
- поддерживаются любые кодировки (utf-8, windows-1251, koi8-r, …) и имена,
  разбитые на несколько строк;
- «кракозябры» чинятся только тогда, когда восстановление доказуемо: имя
  разворачивается обратно и проверяется на строгое соответствие UTF-8. Если
  проверка не сошлась, имя остаётся нетронутым — поэтому настоящие
  европейские имена вроде `Résumé.pdf` расширение не портит;
- письма с цифровой подписью не затрагиваются;
- обычные письма расширение пропускает мгновенно, не замедляя Почту.

Расширение не требует запущенных фоновых программ: Почта сама запускает его
при чтении письма и сама останавливает. Приложение-контейнер просто лежит в
«Программах».

## Установка

Приложение не подписано платным сертификатом Apple, поэтому просто скачать
и открыть его не получится — Gatekeeper заблокирует запуск. Оба способа ниже
решают это автоматически: они снимают карантин и переподписывают приложение
локальной подписью, после чего macOS относится к нему как к собранному на
вашем компьютере.

### Способ 1: установочный скрипт

Откройте Терминал и выполните одну команду:

```sh
curl -fsSL https://raw.githubusercontent.com/borzov/MailFilenameFix/master/install.sh | bash
```

Скрипт скачает последний выпуск, установит его в «Программы» и подскажет,
что делать дальше. Для обновления просто выполните команду ещё раз.

### Способ 2: Homebrew

Cask лежит прямо в этом репозитории — подключите его как tap по URL:

```sh
brew tap borzov/mail https://github.com/borzov/MailFilenameFix
brew install --cask --no-quarantine borzov/mail/mail-filename-fix
```

Обновление: `brew upgrade --cask --no-quarantine mail-filename-fix`.

### После установки

1. Включите расширение: **Почта → Настройки → Расширения → Filename Fix**.
2. Перезапустите Почту.

Уже полученные письма Почта могла запомнить в старом виде — они исправятся
после переоткрытия письма или пересинхронизации ящика. Новые письма
исправляются сразу.

## Сборка из исходников

Нужны Xcode и [xcodegen](https://github.com/yonaskolb/XcodeGen)
(`brew install xcodegen`). Укажите свою команду разработчика
(`DEVELOPMENT_TEAM`) в `project.yml`, затем:

```sh
xcodegen generate
xcodebuild -project MailFilenameFix.xcodeproj -scheme MailFilenameFix \
    -configuration Release build
```

Готовое приложение появится в DerivedData; скопируйте его в «Программы».

## Тесты

Ядро, переписывающее заголовки (`Extension/FilenameFixer.swift`,
`Extension/EncodedWord.swift`, `Extension/MojibakeRepair.swift`), покрыто
автономными тестами — в том числе набором имён, которые трогать нельзя:

```sh
scripts/test.sh
```

## Выпуск новой версии

```sh
scripts/release.sh 1.2.3
```

Скрипт поднимет версию, прогонит тесты, соберёт приложение, упакует его в
`dist/` и обновит Homebrew cask (версию и sha256). Команды публикации
(git push, релиз на GitHub) он напечатает в конце — их нужно выполнить
вручную.

## Удаление

1. Выключите расширение: **Почта → Настройки → Расширения → Filename Fix**.
2. Удалите приложение — перетащите «Mail Filename Fix» из «Программ» в Корзину
   или выполните в Терминале:

   ```sh
   osascript -e 'quit app "Mail Filename Fix"'
   rm -rf "/Applications/Mail Filename Fix.app"
   ```

   Если ставили через Homebrew:

   ```sh
   brew uninstall --cask mail-filename-fix
   ```

3. Перезапустите Почту. Письма при этом никак не пострадают: расширение
   ничего не меняло на сервере, Почта просто вернётся к прежнему
   отображению имён.
